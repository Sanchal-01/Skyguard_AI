11. IMPORTANT EDA RESULTS
-------------------------

A. Strong temporal dependence

Approximate lag-1 autocorrelation:

    avg_temp      ≈ 0.951
    humidity      ≈ 0.919
    dew_point_c   ≈ 0.939
    air_pressure  ≈ 0.948
    wind_speed    ≈ 0.740
    rainfall      ≈ 0.371

Meaning:
Temperature, humidity, dew point and pressure are strongly dependent on
recent observations.

This supports temporal anomaly detection.


B. Strong station-specific differences

Average RH varies significantly between stations.

Examples:
    Thrissur       ≈ 82.8%
    Palakkad       ≈ 81.2%
    Cochin         ≈ 79.1%
    Shimla         ≈ 78.2%
    Ambala         ≈ 62%

Conclusion:
Do not use one global threshold such as:
    "RH > 80% = anomaly"

We need station/season-aware behaviour.


C. Useful cross-variable relationships

Approximate correlations:

    avg_temp ↔ humidity       ≈ -0.518
    avg_temp ↔ dew_point_c    ≈ +0.923
    avg_temp ↔ air_pressure   ≈ -0.780

These relationships can be useful in multivariate anomaly detection.


D. Structural date gaps

Observed whole-row gaps include:

    Ambala       = 2 missing days

Important:
A missing observation is an observed data gap.

cause is unknown.

14. ANOMALY INJECTION PLAN
--------------------------
We have NOT injected anomalies yet.

Next phase will use the clean baseline and create a separate ground-truth dataset.

Main categories:

1. SENSOR FAULT
   - stuck-at value
   - sudden spike/drop
   - gradual drift
   - bias shift
   - cross-sensor inconsistency
   - physically impossible readings

2. TRANSMISSION / COMMUNICATION GLITCH
   - missing record
   - duplicate record
   - delayed / out-of-order record
   - corrupted value
   - null / malformed field

3. GENUINE EXTREME WEATHER EVENT
   - regional temperature event
   - regional rainfall event
   - regional humidity-related event

Core distinction:

    One station changes abnormally
    + nearby stations stay normal
    → likely sensor fault

    Several nearby stations change together
    → likely genuine regional weather event

    Data sequence / communication breaks
    → likely transmission glitch
